À propos

Je m'appelle Jysca. Je travaille à la frontière entre design et développement — deux métiers que la plupart séparent, et que je refuse de dissocier. Une interface mal codée trahit le design ; un design mal pensé complique le code.

Mon approche : prototyper vite en design, puis construire proprement en code — HTML, CSS, JavaScript, React, avec Git pour le versionnage et GitHub Pages pour la mise en ligne. Chaque projet passe par les deux mains, les miennes.

Je conçois pour des marques et indépendants d'Afrique francophone qui veulent une présence en ligne qui leur ressemble, pas un template recyclé.
